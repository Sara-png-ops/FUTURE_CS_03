# FUTURE_CS_03

## API Security Risk Analysis

### Objective
The objective of this project is to analyze the security risks of a public REST API using Postman.

### API Used
JSONPlaceholder REST API

https://jsonplaceholder.typicode.com/

### HTTP Methods Tested
- GET
- POST
- PUT
- DELETE

### Security Checks Performed
- Authentication
- Authorization
- Input Validation
- Data Exposure
- Rate Limiting

### Tools Used
- Postman
- GitHub
