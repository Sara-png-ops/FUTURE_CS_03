# FUTURE_CS_03

## API Security Risk Analysis

### Objective
The objective of this project is to analyze the security risks of a public REST API using Postman.

### API Used
- JSONPlaceholder REST API
- https://jsonplaceholder.typicode.com/

### HTTP Methods Tested
- GET
- POST
- PUT
- DELETE

### Security Checks Performed
- Authentication
- Authorization
- Input Validation
- Data Exposure
- Rate Limiting

### Tools Used
- Postman
- GitHub

### Conclusion
The API was tested using GET, POST, PUT, and DELETE methods. Security analysis showed that the JSONPlaceholder API is intended for testing and does not implement authentication or authorization, making it suitable for learning but not for production use.
